1 · 品牌标志 HGS 为主体，化工社作为中文副标

图形标是一个尖顶六边形，也就是苯环的简化，里面是字母 H，横画是两条平行线，代表化学键里的双键。字标 HGS 用等粗几何线条绘制，和图形标的线条粗细保持一致。HCID 徽标里的六边形也取自这个图形标，品牌和数据标识因此用的是同一个图形。

尺寸与规则

  • 图形标最小 16px；16px 以下只用六边形，不画双键

5 · HCID / HRID 徽标 全站唯一的实体标识组件

徽标由三部分组成：字形、前缀、编号，三者都固定不变。化合物用六边形，反应用箭头，即使黑白打印也能分清两种实体。编号用等宽数字，不加千分位，也不截断。徽标本身就是指向实体详情页的链接。替换现有 EntityId 组件的视觉。

7 · 交互规范 12 条，每条都能验收

IX-1状态完整

  • 可点元素都有 default / hover / pressed / focus-visible / disabled；异步操作加 loading，可选元素加 selected
  • 焦点环 2px --focus，只在键盘操作时出现

IX-2反馈分三层

  • 字段错误：显示在输入框下方
  • 操作结果：Toast，成功 3 秒后消失，失败需手动关闭
  • 页面级失败：Notice，附带重试
  • 禁止使用 alert() / confirm()

IX-3不可逆操作要二次确认

  • 删除反应、删除笔记、撤销 Key、注销账号时弹出确认窗，写明对象名称
  • 确认按钮写具体动作；默认焦点在“取消”；Esc 关闭

IX-4防止重复提交

  • 点击后按钮立即进入 loading，宽度不变
  • 列表加载用骨架屏；超过 10 秒提示“仍在处理”并提供重试

IX-5编辑器保存状态

  • 标题旁显示：已保存 / 保存中 / 保存失败
  • 有未保存的改动时，离开页面要拦截
  • 保存失败不丢用户输入

IX-6社交操作即时生效

  • 关注、收藏点击后立即切换状态，失败时回滚并 Toast 说明
  • “已关注”状态 hover 时文字变为“取消关注”，不需要二次确认

IX-7复制

  • ID、SMILES、InChIKey、Key 旁边都有复制按钮
  • 复制后图标变成 ✓ 并保持 1.5 秒，aria-live 播报“已复制”

IX-8空状态

  • 由图标、一句标题、一句说明和一个下一步操作组成
  • 禁止只写“暂无数据”

IX-9数据来源

  • 每个事实值后面都带来源标签；多个来源不一致时并列显示，不合并
  • 长段证据默认折叠

IX-10键盘

  • ⌘K 或 / 聚焦全局搜索；Esc 关闭浮层
  • 弹窗打开后焦点锁在弹窗内，关闭后焦点回到触发按钮
  • 图标按钮必须有 aria-label

IX-11手机端

  • 触控目标 ≥ 44px，输入框字号 16px
  • 底部 4 个 tab：查询 / 工作台 / 动态 / 我的，留出 safe-area 底部间距
  • 右侧栏移到正文下方；本页导航改成吸顶的横向 tab

IX-12文案

  • 所有界面文字都要进入五种语言的字典
  • 按钮用动词说清做什么；错误信息说明原因和解决办法

13 · 禁止项 写进 CI 测试，违反就失败

在 tokens.css 以外的 CSS 或 TSX 中写 hex 或 rgb 色值
使用 8 档以外的字号，或小于 12px 的可见文字（徽标 xs 前缀除外）
使用 6 / 8 / 12 / 16 / pill 以外的圆角
给卡片或面板加阴影
不经过 EntityBadge 组件，自己拼写 HCID / HRID 的展示
用文字字体排 HGS 字标，或改动标志的颜色和比例
工作台另立一套 --wb-* 取值；使用微信绿或暖橙
使用 alert() / confirm()；去掉焦点样式却不提供替代

实现范围：只改 web 前端和品牌资源，不改 API、MCP 或数据模型。“常用化合物”模块需要新接口，留到 v1.8。后台 /samelabs 只把 token 换成别名。
