# HGS 设计系统 v2.0

状态：**v2.0**（2026-10-13），取代 v1.0。

准线：**以美观为准**。实现符合规范但不好看，说明规范没覆盖或约定有误，修规范，不以“合规”验收。

体系分六层，每层只依赖下层：基础 → 布局与框架 → 组件 → 交互 → 模式 → 页面。页面只由框架和模式组成，模式只由组件组成，组件只用基础层的取值。**不写页面级特例样式。**

唯一来源：

| 来源 | 内容 |
|---|---|
| `web/app/tokens.css` | 全部取值 |
| 本文档 | 规则、组件契约、交互、模式、页面结构 |
| `web/components/ui/` | 组件实现 |

非目标：不改数据库、身份裁定、API / MCP 语义；不做暗色模式。

## 第一层：基础

### 1.1 品牌

- 图形标：尖顶六边形，里面是字母 H，横画是两条平行线（双键）。字标 HGS 以 SVG 路径交付，不用文字字体排版。
- 中文副标“化工社”只在 `zh-CN` 横版组合中出现，与字标之间用 1px × 16px 分隔线隔开；其他语言只显示 HGS。
- 品牌源文件在仓库外 `brand/` 目录（不入库；`brand/build-brand-assets.mjs` 生成 public/app 图标产物，产物入库）：`hgs-mark.svg`（浅色底）、`hgs-mark-on-dark.svg`（深色底）、`hgs-mark-line.svg`（品牌色底、App 图标）、`hgs-mark-16.svg`（favicon）、`hgs-wordmark.svg`、`hgs-lockup.svg`（OG 图）、`hgs-app-icon.svg`（PWA）。
- React：`<HgsLogo variant="lockup" | "mark" | "wordmark" size />`。尺寸：桌面顶栏 28，手机顶栏 24，登录卡和空态 44；组件最小 20，16 只用于 favicon。
- 四周留白 ≥ 图形标宽度的 1/4。不加渐变（App 图标除外）、阴影、描边；不改比例和颜色。

### 1.2 颜色

只有一种品牌色：蓝。绿、琥珀、红只表示状态。

| 语义 token | 用途 |
|---|---|
| `--text` / `--text-2` | 标题和数据值 / 次要正文 |
| `--text-muted` | 标签、元数据；可读文字的最浅一档 |
| `--text-placeholder` / `--text-disabled` | 只用于占位符和禁用态 |
| `--action` / `-hover` / `-pressed` | 按钮、链接 |
| `--action-subtle` / `--action-ink` | 浅蓝底和其上的文字（tonal 按钮、选中项） |
| `--brand` / `--focus` | 标志、焦点环、选中指示条。不能用作文字颜色 |
| `--bg-page` / `--bg-surface` / `--bg-subtle` | 页面底 / 卡片 / 次级面和 hover |
| `--border` / `--border-strong` | 卡片和分割线 / 输入框和次按钮 |
| `--entity-chem*` / `--entity-rx*` | 只用于 EntityBadge |
| `--ok*` / `--warn*` / `--err*` | 只表示状态 |
| `--bg-inverse*` / `--text-inverse*` / `--code-inverse` | 只用于 Toast、后台深色侧栏、深色代码块 |

数字、统计值不用状态色装饰。

### 1.3 字体与字号

- 字体：`--font-ui`（系统字）。`--font-mono` 只用于 ID、SMILES、InChIKey、代码和 Key；数字列加 `tabular-nums`。
- 字号 8 档，取值见 tokens：

| token | 用途 |
|---|---|
| `--fs-40` | 首页标题、实体名（桌面）；手机用 28 |
| `--fs-28` | 页面标题、统计数字 |
| `--fs-22` | 分区标题（h2） |
| `--fs-18` | 弹窗标题、空态标题、组标题（h3） |
| `--fs-16` | 正文、卡片标题、手机端输入框 |
| `--fs-14` | 界面默认：按钮、输入、数据值 |
| `--fs-13` | 元数据、面包屑、侧栏分组名 |
| `--fs-12` | 说明、Tag、时间戳 |

- 最小 12px。唯一例外：EntityBadge xs 的前缀 11.5px。
- 字重 400 / 500 / 600；22 及以上用 650，配对应的负字距（`--ls-*`）。

### 1.4 间距

`--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-6` 24 · `--sp-8` 32 · `--sp-12` 48 · `--sp-16` 64。

纵向节奏（所有页面相同）：

| 位置 | 桌面 | 手机 |
|---|---|---|
| 顶栏到面包屑 / 页头 | 32 | 16 |
| 页头到正文 | 32 | 24 |
| 分区之间 | 48 | 32 |
| 分区标题到内容 | 16 | 12 |
| 卡片内边距 | 24 | 16 |
| 页面左右留白 | 居中容器 | 16 |

### 1.5 圆角、阴影、高度

- 圆角：`--r-xs` 6（Tag、徽标）· `--r-sm` 8（所有按钮、输入框、Segmented）· `--r-md` 12（卡片、面板）· `--r-lg` 16（弹窗、抽屉）· `--r-pill`（头像、计数）。
- 卡片和面板只用 1px `--border` 分层，不加阴影。`--shadow-float` 只用于下拉菜单、弹窗、Toast。
- 控件高度：`--h-sm` 32 · `--h-md` 40 · `--h-lg` 48。手机上可点目标以**真实尺寸 ≥ `--touch-min` 44** 落地（按钮 / 复制钮 / 表单控件 / 图标钮宽度）；不用伪元素扩热区——真实尺寸可被运行时断言验证，伪热区不改变 getBoundingClientRect 且相邻热区互相争抢。链接徽标（EntityBadge）是唯一例外：设计高度不变，用 `::after` 透明热区补足（徽标本体是信息展示，拉高会破坏四档高度体系）。

### 1.6 图标

四档，token 化（见第八章）：

| 档位 | 用途 |
|---|---|
| xs 16 | Tag、徽标内 |
| sm 18 | sm 尺寸按钮、输入框内、Toast |
| md 20 | 默认按钮内（含图标按钮、铃铛、复制、分享）、Notice、卡片入口 |
| lg 24 | 底部 tabbar、空态、状态页 |

- 同一行图标同一档；图标声明 `flex: none`，不受 `max-width` 压缩。线宽保持 2（24 视口下）。
- 图标统一取自 `components/ui/icons.tsx`，不另画。

### 1.7 动效

`--dur-fast` 120ms（hover、按压，按下缩到 0.98）· `--dur` 200ms（浮层进出）· `--ease`。用户开启“减少动态效果”时全部关闭。

## 第二层：布局与框架

### 2.1 断点

| 档 | 宽度 | 规则 |
|---|---|---|
| 手机 | ≤ 640 | 单列；顶栏 52；底部 tabbar；没有侧栏和右栏 |
| 平板 | 641–1023 | 顶栏 60；侧栏保留；实体详情右栏下沉到正文下方；不出现三列 |
| 桌面 | ≥ 1024 | 完整布局 |

任何一列的内容宽度不得小于 320。每个页面都要在三档下成立。

### 2.2 容器与列

- 容器：`--w-reading` 720 · `--w-content` 1040 · `--w-wide` 1200。组件不得自定页面级 max-width。
- 列：侧栏 `--sidebar-w` 232（桌面和平板相同）· 详情右栏 `--rail-w` 260。（工作台右栏社交列已删除——通知由铃铛与通知面板单一表达，`--rail-w-wide` 随之废除。）
- **全站布局架构（I-047/I-085，2026-10 定稿，唯一架构）**：
  - `html` 一律 `scrollbar-gutter: stable` —— 短页与长页共用同一内容盒，页面间切换时左边界不漂移。
  - 满屏框架：根布局唯一挂载 `.sh-frame`（min-height 100dvh 的纵向 flex），外壳顶栏与页面同框架，页面容器（公开页 `.app-container` / 工作台 `.wb-shell`）以 `flex: 1` 填满顶栏以下剩余高度；全站统一随文档滚动，页面容器不自持滚动、不用 fixed inset 铺屏。
  - 顶栏吸顶让位：顶栏 sticky 后，页内吸顶元素与锚点统一用 `--header-clear`（含顶栏高、1px 底线与顶部安全区）让位；手机底栏让位全站一条 `--tabbar-clear`（公开页正文与工作台正文共用）。
  - 所有公开页共用一个外框：宽 `--w-wide` 1200，左右边距按现有断点；**顶栏 logo 左边缘就是内容左边缘**，任何公开页不得偏离。
  - 内容宽度分档 wide 1200 / content 1040 / reading 720；正文页（详情 / 列表 / 文档）在容器内用更窄的分档限行长，从外框左边缘起排。**首页例外：首屏（hero、检索、入口）居中呈现**——检索引导页式首屏居中是通用形态，不套用左对齐。
  - 唯一表单例外：登录、注册等单卡表单页（框架 E，`--w-form` 400，卡片居中）。
  - 工作台（框架 D）所有页面（各 Tab 与 `/me/settings/*`）共用同一个栅格：桌面主列左边缘与宽度固定，切换 Tab 不变；容器与公开页同宽（wide 1200，侧栏左边缘 = logo 左缘），单主列。

### 2.3 外壳（所有页面共用，只有一份实现）

- **桌面顶栏（60）**：横版标志 · 主导航（首页 · Skills · MCP · 工作台）· 通知铃铛（未读红点）· 语言切换 · 头像菜单（未登录时为“登录 / 注册”）。白色不透明底，吸顶（iOS 据此绘制屏幕顶边；页内吸顶元素与锚点让出顶栏高度）。**顶栏不放搜索框，不设搜索快捷键。**
- **手机顶栏（52）**：全站一套 —— 标志 · 汉堡抽屉 ≡（登录即显示，匿名只有标志与语言）· 语言切换。抽屉含快捷操作、语言、工作台导航、账户设置与退出登录（退出与桌面头像菜单共用同一实现）；创建入口在抽屉快捷操作内，顶栏不设独立「+」。
- **底部 tabbar（手机）**：首页 / 工作台 / 通知（未读数）/ 我的。内容区高 56，safe-area 加在下方，不占内容高度。「我的」直接落本人公开主页（主页区分主人态/游客态，设置、退出在主人态与头像菜单承载）。
- **底栏选中态规则（I-095）**：公开内容页（搜索、化合物、反应、笔记、Skills、MCP 指南、指南、法务页等）归入“首页”tab 高亮 —— 即除工作台族（`/aichem`、`/submit`、`/me`）、通知、登录/注册/OAuth 授权页、以及“我的”族（`/user/{name}`、`/me/settings`）之外的路由都算公开内容。工作台、通知、“我的”的高亮规则不变；“我的”族页面不得同时点亮“首页”。
- **页脚**：所有公开页和状态页都有（`.sh-footer`）；手机 ≤640 不显示，导航由底部 tabbar 承担。
- **工作台侧栏（232）**：四组 —— 工作区（概览 / 笔记 / 我的反应 / 收藏）、工具（查询 / 投料计算 / Skills / MCP 与 AI Key）、社交（通知 / 关注 / 粉丝）、账户（设置）。任一时刻只高亮一项。

### 2.4 页面框架

| 框架 | 容器 | 桌面 | 平板 | 手机 |
|---|---|---|---|---|
| A 公开页 | wide（正文限 reading 720 左对齐） | 单栏，左边缘与 Logo 对齐 | 单栏，左右留白 24 | 单栏 |
| B 实体详情 | wide | 面包屑 → 页头（左信息 + 右结构图 300）→ 正文 + 右栏 260 | 结构图 240；右栏下沉到正文后 | 结构图在页头顶部；本页导航改为吸顶横向 Tabs；右栏内容下沉 |
| C 阅读 | wide（正文限 reading 720 左对齐） | 单栏，无侧栏 | 同桌面 | 单栏 |
| D 工作台 | wide（与公开页同宽，侧栏 + 主区） | 侧栏 + 主区 | 侧栏 + 主区（主区单列） | 无侧栏，靠 tabbar |

### 2.5 公开资源（有界化与边缘缓存）

对外只暴露有限个、带扩展名、可长期缓存的资源 URL；参数一律走白名单。

#### 1. 结构图尺寸档位（`MOL_SVG_SIZES`）
所有调用方收敛为 4 档 4:3 比例标准尺寸，禁止任意尺寸传参：
- **lg (280×210)**：化合物详情页结构大卡片
- **md (160×120)**：搜索结果、工作台面板中型卡片
- **sm (112×84)**：实体卡片、工作台收藏列表等小卡片
- **xs (64×48)**：反应参与物缩略图、工作台首页微缩图
路由 `/api/mol/{id}/svg/{W}x{H}.svg` 仅接受白名单尺寸，其余一律 404。

#### 2. 资源路由形态
所有对外图片均使用带扩展名的伪静态资产路径，禁止向公网暴露查询参数形式的实时渲染接口：
- 分子结构图：`/api/mol/{id}/svg/{W}x{H}.svg`（仅限 4 档白名单尺寸）
- 化合物分享图：`/api/mol/{id}/png/800x800.png`（白底方形留白，唯一尺寸）
- 反应分享图：`/api/reactions/{id}/png/1200x630.png`（横版）与 `/api/reactions/{id}/png/800x800.png`（方形白底，微信 itemprop），仅此两档固定尺寸
- 通用 BFF 代理对 `/api/mol/{id}/(svg|png)` 及 `/api/reactions/{id}/(svg|png)` 等无扩展名查询接口一律拦截返回 404。

#### 3. 缓存策略（边缘与源站）
- **化合物结构图与分享图**：化合物无私有态，不再转发 cookie，统一响应 `Cache-Control: public, max-age=31536000, immutable`。
- **反应方程式图与分享图**：公开反应响应 `Cache-Control: public, max-age=300`；带身份会话请求或私有反应响应 `Cache-Control: private, no-store`，禁止进共享缓存。
- **匿名公开页边缘缓存（Cloudflare 方案 1）**：
  - 范围：带 locale 前缀的公开页（首页、搜索、化合物、反应、笔记、公开主页、Skills、guide、mcp-guide、privacy、terms、support）。
  - 请求未带登录 cookie（`hgs_session`）时：`Cache-Control: public, max-age=0, s-maxage=300, stale-while-revalidate=86400`。
  - 请求带登录 cookie 时：保持 `Cache-Control: private, no-store`。
  - 不缓存：工作台、设置、登录、提交、管理端、未带 locale 前缀的 307 重定向跳转。
  - 匿名 HTML 严禁包含任何与访问者相关的标记（CSRF / 会话标记）。

## 第三层：组件

组件在 `web/components/ui/`，类名前缀 `.hg-`。每个组件实现全部状态（见第四层 IX-1）。每个变体都写明使用场景，同一场景只有一种选择。

### 3.1 Button

| 变体 | 场景 |
|---|---|
| primary | 区域内唯一的主操作：保存、提交、新建反应、收藏（详情页头）、查询 |
| secondary | 与主操作同级的次操作：新建笔记、子结构检索、相似结构、分享、编辑 |
| tonal | 空态的下一步、卡片内的轻操作（关注） |
| ghost | 列表行和通知条目上的操作、翻页 |
| danger | ConfirmDialog 里的最终确认 |
| danger-quiet | 列表行内的删除、撤销 Key |

- 尺寸：lg 48（首页搜索、手机主操作）· md 40（默认）· sm 32（行内、卡片内、列表行）。圆角都是 8。
- 图标 16；同一组按钮要么都有图标，要么都没有。icon-only 必须有 aria-label，图标在任何断点都可见。
- 宽度：一律按内容自适应，任何场景、任何断点都不撑满；主操作用 lg 尺寸保证点击区域。
- 每个区域只有一个 primary；loading 时宽度不变、禁止再点。

### 3.2 TextLink

行内文字动作（返回首页、查看全部、启用 / 停用）。不加边框和底色。

### 3.3 Field 与输入控件

- Field：label 在上，必填星号紧跟 label 文字、同一行；help 在下；error 红字在下。label 与控件用 htmlFor 关联。
- Input / Select / Textarea：高 40，圆角 8，`--border-strong`；焦点为 `--focus` 边框加 4px `--focus-halo`；手机字号 16。
- FileUpload：Button secondary 触发隐藏的 file input，旁边显示已选文件名，不露出浏览器原生控件。

### 3.4 EntityBadge

全站唯一的 HCID / HRID 展示组件。

```
<EntityBadge kind="chemical" | "reaction" id size="xs" | "sm" | "md" | "lg"
             href? copyable? compact? state?="private" | "merged" | "deleted" redirectTo? />
```

- 结构：`[字形][前缀] | [编号]`。前缀段实体色浅底，编号段白底，1px 实体色描边，圆角 6。化合物字形为六边形，反应为箭头。
- 尺寸：lg 32（详情页头）· md 28（卡片标题）· sm 24（列表、搜索结果、参与物）· xs 20（卡片内的关联实体）。
- 编号等宽、tabular-nums，不加千分位、不补零、不截断。前缀不翻译。
- `compact`（只有字形和编号）只用于表格列，其他地方一律用完整徽标。
- 状态：private 编号后加锁；merged 虚线边框、编号删除线、后接 → 新编号徽标；deleted 虚线边框、删除线、后跟“已删除”。
- hover 边框变实体色；aria-label 取字典（“HCID 2244，化合物”）。

### 3.5 CopyButton 与 CodeField

- CopyButton 只有一种：桌面外观 28 × 28、图标 16；手机按真实尺寸落 44 × 44。行内使用时 `inline-flex`；DataRow 场景值在左、复制钮靠行尾，各行复制钮落在同一竖线。
- 复制后图标变为 ✓ 并保持 1.5s，aria-live 播报。
- CodeField：只用于独立的长串（反应 SMILES、Key、MCP 端点、代码块），右上角内置 CopyButton。同一个代码块一页只出现一次。数据分区里的标识符不用 CodeField，用 DataRow。

### 3.6 Tag

高 24，圆角 6。neutral · blue · ok · warn · err。状态 Tag 带圆点。没有来源 Tag。

### 3.7 Segmented 与 Tabs

- Segmented：同一份数据的视图或模式切换（检索方式、相关反应的角色筛选、登录 / 注册）。
- Tabs：不同数据集之间切换，选中条 2px 落容器内（底线 1px 以背景绘制、被选中条盖住），带计数；tab 条只许横向滚动（`overflow-y: hidden`——overflow-x:auto 会把纵轴连带算成 auto，超出 1px 即可上下滚）。
- 两者放不下时横向滚动，溢出一侧有 24 渐隐提示，不截断文字。
- 一屏只有一层 Tabs。

### 3.8 Breadcrumb

`首页 / 栏目 / 当前`。首级“首页”可点；栏目为不可点击的文字；末级 = 页面 H1 的文本。字号 13。

### 3.9 Notice 与 Toast

- Notice：页面级提示，info · ok · warn · err，图标 20，可带一个操作。
- Toast：底部居中；成功 3s 消失，失败手动关闭；可带“撤销”。

### 3.10 ConfirmDialog

标题是问句，正文写明对象名称；确认按钮写具体动作（“删除笔记”）；默认焦点在“取消”；焦点锁在弹窗内；Esc 关闭并回焦触发按钮。

### 3.11 EmptyState 与 Skeleton

- EmptyState：图标 24（放在 48 的浅底方框里）· 标题一句（18）· 说明最多一句（14）· 恰好一个下一步动作（tonal sm 或 TextLink）。
- Skeleton：与真实内容同尺寸，用于首屏和列表加载。

### 3.12 Avatar

24 / 32 / 40 / 80。无图时显示首字，底色由用户 id 在 `--avatar-1…5` 中确定。

### 3.13 EntityCard

搜索结果、收藏、公开主页统一使用：结构缩略图（或反应式）· EntityBadge sm · 名称 · 一行标识 · 收藏按钮（ghost sm）。

### 3.14 DataRow

- `dl` 两列：标签列 140（手机 96），`--text-muted`；值 `--text`。
- 标识符（SMILES、InChIKey、CAS）为等宽值 + 行内 CopyButton。
- 一个分区内的所有内容都是 DataRow，行高和分割线一致；补充说明也作为一行（标签“其他”）。

### 3.15 GroupToggle（组级折叠）

- 折叠按钮**永远单独占列表下方的一行**，不得放进 `flex-wrap` 的胶囊行（别名、上下游、技能标签等同类写法一律如此）—— 否则会把同一行的胶囊拉高变形（I-079）。
- 超限项以 `hidden` + `data-overflow` 留在 DOM（同一 `id` 容器内），按钮只翻转可见性；“共 N 条”使用接口返回的总数字段，不用已渲染条数。
- 详情页各分组默认可见 6 项（`GROUP_ITEM_LIMIT`），上下游每向默认可见项数另定（`UPDOWN_TAG_LIMIT`）。

## 第四层：交互

| 编号 | 规则 |
|---|---|
| IX-1 | 可点元素都有 default / hover / pressed / focus-visible / disabled；异步操作有 loading，可选元素有 selected。焦点环 2px `--focus`，只在键盘操作时出现。 |
| IX-2 | 反馈分三层：字段错误在输入框下方；操作结果用 Toast；页面级失败用 Notice 加重试。不用 `alert()` / `confirm()` / `prompt()`。 |
| IX-3 | 删除反应、删除笔记、撤销 AI Key、注销账号必须经过 ConfirmDialog。 |
| IX-4 | 异步按钮点击后立即 loading 并禁止再次点击；列表用 Skeleton；超过 10s 显示“仍在处理”并提供重试。 |
| IX-5 | NoteEditor / SubmissionForm 显示保存状态（已保存 / 保存中 / 保存失败）；有未保存改动时离开页面要拦截；保存失败不清空输入。 |
| IX-6 | 关注和收藏乐观更新，失败时回滚并 Toast；成功 Toast 带“撤销”；“已关注”hover 显示“取消关注”。 |
| IX-7 | ID、SMILES、InChIKey、Key 都可复制，反馈见 CopyButton。 |
| IX-8 | 空状态必须给出下一步，不写“暂无数据”。 |
| IX-9 | 页面只展示化学事实，不展示采集来源、流程状态等内部信息；数据冲突并列显示，不自动合并；长段证据默认折叠。 |
| IX-10 | Esc 关闭浮层；弹窗关闭后焦点回到触发按钮；图标按钮有 aria-label。不设全局搜索快捷键。 |
| IX-11 | 手机端：可点区域 ≥ 44；操作放不下时收进“更多”菜单，不隐藏、不删减。 |
| IX-12 | 界面文字全部进入五种语言字典，标点按各语言习惯；按钮用动词说清做什么；错误说明原因和解决办法，不暴露错误码。空态、错误、提示：标题一句，说明最多一句，不重复标题。 |
| IX-13 | 状态互斥，按优先级只显示一种：后台获取中（Notice + Skeleton）→ 读取失败（Notice err + 重试）→ 真正为空（EmptyState）→ 正常内容。 |

### 4.1 状态页

- **404**：任何 404 都有完整外壳，包括未匹配任何路由的地址（根级 `app/not-found.tsx` 也渲染外壳）。EmptyState 标题取 `error.notFoundTitle`，两个出口：去查询（tonal）+ 返回首页（TextLink）。robots 只有一条 noindex。
- **错误边界**：外壳完整；EmptyState + “重新加载”；文案说明数据未丢失、可重试，不暴露技术细节。
- **未登录**：说明一句 + 登录按钮；登录后按 `next` 回跳。

### 4.2 详情页篇幅

- 每个 h3 组默认显示前 6 项（DataRow 与已折叠的 details 各算 1 项）；其余以 `hidden` + `data-overflow` 留在 DOM，组底“展开全部 N 项 / 收起”（aria-expanded / aria-controls）。
- 供应商为紧凑行（公司名 + 电话 + 邮箱），默认 5 家，“查看全部 N 家”。上下游 Tag 每向最多 12 个。
- 没有内容的分区不渲染，本页导航同步省略。

### 4.3 表单

- 所有表单声明 `method="post"`。
- 每张卡一个保存动作；保存中 Button loading；成功 Toast，失败 Notice err 并保留输入，迟到的返回不覆盖已编辑的字段。
- 提交错误按状态和机器码渲染本地化文案（429 限流 / 401 凭证不符 / 409 已被占用），不显示服务端原文；出错后焦点到第一个出错字段。

## 第五层：模式

### 5.1 页头

- 结构：面包屑（如果该页有）→ H1 → 副标题一行 → 标识标签一行 → 操作组。实体页右侧为结构图或反应式。
- **实体详情标题字号**：化合物名称与反应标题都是 h1 —— 桌面 28 / 手机 22，半粗 600（--fw-semibold），行高 --lh-heading，字距 0。
- **HCID 徽标位置**：化合物详情页的 HCID 徽标在标识标签行首位（size sm、可复制），标题行不放徽标；反应详情页的 HRID 徽标随标题行。
- **化合物标题**：中文名 → 英文名 → IUPAC 名 → 分子式 → CAS。不显示“化合物记录 HCID n”这类系统文案；标题已用分子式时，标识标签里不再重复分子式。
- **反应标题**：主要反应物 → 主要产物，句式由各语言字典给出；名称都缺失时用字典里的“反应 HRID n”。不用“反应详情”这类栏目名作标题。
- **结构图**：加载失败或没有结构时显示占位（图标 24 + “暂无结构图”），不显示 alt 文本。

### 5.2 面包屑

只有下列页面有面包屑，写法固定：

| 页面 | 面包屑 |
|---|---|
| 化合物详情 | 首页 / 化合物 / 标题 |
| 反应详情 | 首页 / 反应 / 标题 |
| 笔记详情 | 首页 / 笔记 / 标题 |
| 公开主页 | 首页 / 用户显示名 |
| Skills | 首页 / Skills |
| 文档页 | 首页 / 页面名 |

首页、搜索、登录、状态页、工作台内的所有页面（含设置）没有面包屑。

### 5.3 分区

- 分区标题 h2（22）；组标题 h3（18）。分区按化学语义组织，不按来源分组。
- 分区内容是 DataRow、卡片网格或正文中的一种，不混排。

### 5.4 列表与卡片

- 列表行高 56（紧凑 44），行间 1px `--border`。行内操作用 ghost sm，删除用 danger-quiet sm。
- 卡片网格间距 16；手机单列。
- **列表必须有界（I-083）**：凡消费接口数组渲染进 DOM 的地方，要么分页（页码进 URL，“共 N 条”用接口总数字段），要么默认显示固定条数 + “查看全部 / 展开”折叠（见 3.15 GroupToggle）。不得把任意长度的数组一次性全部渲染；后端嵌数组同样带硬上限与总数字段。

### 5.5 操作组

- 一组里只有一个 primary，其余 secondary；按钮之间 8。
- 图标规则见 Button。
- 手机端：最多并排两个按钮（主操作 + 一个次操作），其余进入“更多”菜单。

### 5.6 页面标题区（工作台和设置）

H1（28）+ 一句说明 + 右侧操作组。没有面包屑。

## 第六层：页面

每页写明框架和组成顺序。页面上出现的内容只限现有功能。

### 6.1 首页 `/`（框架 A，wide）

标题（40，手机 28）与一句说明 → 主搜索框（lg）+ 检索方式 Segmented（居中于搜索框下方）→ 入口卡（「AI 接入」小标题 → MCP 端点 CodeField → 入口按钮 MCP 接入 / Skills / 网页工作台 / Agent Plugin）。入口自适应折行，按钮按内容自适应。

### 6.2 搜索 `/search`（框架 A，wide，正文阅读宽左对齐）

### 6.3 化合物详情 `/chemical/[id]`（框架 B）

- 页头：标题 · 英文名或 IUPAC 名 · 标识标签（HCID 徽标 sm 可复制居首 · 分子式 / 分子量 / CAS，CAS 胶囊内部末尾带复制按钮，全行 28px 等高）· 操作组（分享 / 打印 + 收藏 primary + 子结构检索 · 相似结构进“更多”）· 结构图。

### 6.4 反应详情 `/reaction/[id]`（框架 B）

- 页头：标题（HRID 徽标随标题行，可复制）· 署名行 · 操作组（分享 / 打印 + 关注或本人操作）。无事实摘要行。
- 正文：反应式（占满正文宽度，下方是反应 SMILES 的 CodeField）→ 反应物和产物（EntityBadge sm）→ 助剂 → 条件（DataRow）→ 步骤 → 后处理 → 安全和备注 → 来源与引用（ORD / DOI / 专利）。
- 页头署名行：Byline（作者头像+名，链接主页）+ 非作者的关注作者入口 + 私有标记；作者视角对被隐藏反应显示 Notice 提示。记录卡 / 作者卡不再出现（记录事实归正文，作者归署名行）。
- 右栏：本页导航。来源与引用只在正文出现一次。

### 6.5 笔记详情 `/note/[id]`（框架 C）

- **标题规则（I-080/I-081，全站唯一 resolver：`lib/noteHeadline.ts`，详情页、信息流卡片、metadata 共用）**：笔记有两行及以上、且首行不超过 60 字 → 首行作为标题，其余作为正文；其他情况（单行或首行过长）→ 整段作为正文，标题用中性写法：关联了实体时“关于 {实体名} 的笔记”，没有关联时“{作者显示名} 的笔记”。不再把整段内容当 H1。
- 阅读页：面包屑与标题按规范留出间距 → 标题（28）→ 作者 Avatar + 名字 · 日期 · 可见性 Tag 作为一行 meta → 正文（16 / 1.65，reading 宽度阅读体）→ 关联实体（EntityBadge xs 列表，放正文后）→ 本人可见：编辑（secondary）、删除（danger-quiet）。正文直接排在页面上，不包在孤立卡片里；短笔记不留大片空白。
- 信息流卡片（工作台通知）：作者行 → 标题（粗体一行）→ 正文摘要（最多 3 行）→ 关联实体徽标，层级一眼可分。

### 6.6 公开主页 `/user/[username]`（框架 B，无本页导航，单栏）

- **短地址（I-084）**：`/u/{username}` 是稳定入口（按现行用户名规则校验，非法 404），307 到 `/{locale}/user/{username}`（cookie > Accept-Language > en 的协商顺序），`Cache-Control: private, no-store`；带 locale 前缀的 `/ja/u/x` 不当作别名（404）。主页的分享与复制链接一律使用 `https://huagongshe.com/u/{username}`；`/user/` 路由与 canonical 不变。
- 面包屑 → 名片：Avatar 80 · 名字（28）· @用户名 · 关系 Tag · 简介 · 机构和加入时间 · 数字（公开反应 · 公开笔记 · 粉丝 · 关注）· 操作（访客：关注 primary + 分享；本人：编辑资料 + 进入工作台 + 分享）→ Tabs（反应 / 笔记）→ 反应两列卡片 / 笔记列表。名片里出现过的信息不再重复。

### 6.7 工作台 `/aichem`（框架 D）

- 页面标题区：问候语 + 一句当前状态；操作组：新建笔记（secondary）+ 新建反应（primary），都带图标。
- 概览（桌面双列：快捷检索/入口列 + 我的内容列；平板和手机单列）：
  - 快捷列：快速检索 + 4 个快捷入口（2 × 2）。
  - 我的内容列：“我的内容”面板（Tabs：最近 / 反应 / 笔记 / 收藏；每行类型图标 · 标题 · 徽标 · 可见性 · 时间，笔记显示保存状态）。

- 排版：字体统一（无衬线）、分节标题清楚、表格行不跨页断行（`break-inside: avoid`）、页码依赖浏览器打印对话框的能力。

## 第七章：禁止项（由 `tests/test_ui_token_contract.py` 在 CI 检查）

1. 在 `tokens.css` 以外写 hex / rgb / hsl 色值（品牌 SVG 除外）。
2. 字号不在 8 档内，或可见文字小于 12px（EntityBadge xs 前缀除外）。
3. 圆角不在 6 / 8 / 12 / 16 / 999 之内；给卡片或面板加 box-shadow。
4. `--wb-*` 自带取值；出现 `--green*` / `--warm*`。
5. 调用 `alert(` / `confirm(` / `prompt(`。
